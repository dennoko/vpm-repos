dennokoworks.vpm

dennokoworks 製 Unity / VRChat 向けエディタ拡張ツールの公式 VPM パッケージ配信リポジトリです。

INSTALL
Add to VCC
VCC にリポジトリをワンクリックで追加
手動追加の手順を表示
  1. 上の Copy URL ボタンでリポジトリ URL をコピー
  2. VCC (VRChat Creator Companion) を起動
  3. 左サイドバーの Settings ＞ Packages タブを開く
  4. Installed Repositories の右上にある Add Repository をクリック
  5. コピーした URL を貼り付け、Add を押して登録完了

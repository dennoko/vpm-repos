dennokoworks VPM Repository

dennokoworks 製 Unity / VRChat 向け拡張ツールの公式配信リポジトリです。

VCC に追加 (Add to VCC)

※ VCC (VRChat Creator Companion) が導入されている PC 環境でクリックすると追加ダイアログが開きます。

または手動で登録
手動追加の手順を見る
  1. 上の「コピー」ボタンを押してリポジトリの URL をコピーします。
  2. VCC (VRChat Creator Companion) を起動します。
  3. 左メニューの Settings ＞ Packages を開きます。
  4. Installed Repositories の右上にある Add Repository をクリックします。
  5. コピーした URL を貼り付けて Add をクリックします。
